# Raspored treninga ŠK Odra

U ovom repozitoriju je samo raspored treninga (`training.json`). Treneri ga uređuju na
**https://ADRESA-STRANICE/admin/trener/** i nemaju pristup ostatku web-stranice.

Nakon spremanja radnja *Obavijesti web-stranicu* (`.github/workflows/notify-site.yml`) pokrene
objavu web-stranice, pa je promjena na stranici za otprilike 2 minute.

Postavljanje: vidi `docs/CMS.md` → „Uloge: administrator i trener” u repozitoriju web-stranice.
