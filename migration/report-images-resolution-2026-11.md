# Image resolution audit – November 2026

Scope: every photo stored with the articles and gallery (`src/content/blog/hr/*`, `src/content/gallery/*`), 1215 files. Each was compared with every larger file in the old WordPress media library: the 1637 files of the migration mirror plus the 180 media originals that were not in the mirror (downloaded read-only for this audit; 6 return 404 on the old site).

**Verification method.** A candidate had to (1) have the same aspect ratio (±3 %), (2) match a perceptual fingerprint (32×32 grey + dHash), (3) score a pixel PSNR of at least 25 dB (tiny thumbnails score lower because of their own compression) after being scaled down to the current file's size, and (4) pass a side-by-side visual check by eye. Filenames were not used as evidence.

**Result in one line:** 72 photos have a verified higher-resolution original and were replaced; 4 photo candidates were rejected or left for a decision; for the remaining low-resolution photos the WordPress original is itself the same size, so no better version exists in the old media library.

Counts: section 1 = 72, section 2 = 4 photos + 2 copies of a 15 px spacer, section 3 = 980 files up to 1100 px (larger files were already high quality; 10 files were capped at 2400 px by the migration and are left as they are).

## How the replacements were made

- Same filename, same folder, so every Markdown, gallery and CMS reference stays valid. No article text, gallery album or image order was touched.
- The original file is now the source; the site still generates its responsive WebP sizes (and the lightbox's up-to-2000 px WebP) from it at build time. No AVIF.
- Originals up to 2400 px wide were copied byte for byte apart from their metadata block (EXIF/XMP, which in two files contained GPS coordinates). The three originals wider than 2400 px were scaled to 2400 px, the same cap the migration used.
- No second copy of any photo was added. The old WordPress site was only read.
- Eight of the replaced files were small single thumbnails inside the article text (180–450 px: ekips250, odrasisak250, cureskolsko300, deckiskolsko300, speharom700, zadnjekolo700, banjelacicodra2, odra-vs-karlovac-s). They used to appear at that small size; they now display at the normal article-photo width, sharp, like the other photos. Thumbnails that sit in an image grid keep the grid size and are simply sharper.
- Photos inside article text now get a responsive WebP `srcset` (480/800/1200/1600 px, never larger than the original), so a phone no longer downloads a 2000+ px file; the lightbox still opens the full-size WebP.
